## Rulings et adjudications (exhaustif, chronologique)

1. Défauts de plan corrigés préflight : test bats dry-run cassé sur macOS (`detect_arch` arm64→aarch64) ; vérification post-install de `/boot` imposée (wrapper mkinitcpio amont ne propage pas les codes retour). 2. Spike rendu : `LIBGL_ALWAYS_SOFTWARE=1` = réglage du banc VM, jamais des paquets ; le repli `QSG_RHI_BACKEND` nommé par la spec n'existait pas (errata). 3. Règle de propriété réécrite après mesure : l'arbre `~/.config/hypr/` ENTIER appartient à DMS ; accroche par `dms/binds-user.lua` (canal béni amont), premier boot résolu par wrapper de session (`dms setup` complet = mur sudo mesuré) ; trou amont comblé (`hyprland-session.target` inexistant, livré par le paquet). 4. Verdict polkit : « Not available » de `dms doctor` = faux négatif prouvé — aucun agent externe. 5. Préset appliqué par hook alpm idempotent (marche aussi en pacstrap — garde volontairement ≠ de celle d'Arch, mesurée des deux côtés). 6. `pipewire-pulse` = correction, pas précaution (pipewire ne livre aucun SPA audio) — inventaire amont corrigé. 7. Trou FileChooser réel (xdph ne l'implémente pas, aucun repli empaqueté) → arbitrage écran en main : `xdg-desktop-portal-gtk` ajouté (la chaîne du paquet `hyprland` le préfère). 8. **Règle polkit `YES` sans authentification supprimée en revue** : le rollback de la racine exige la modale (auth_admin, prouvée par captures + rc=126) — cohérence avec la posture sudo du Socle ; « on part fermé ». 9. `btrfs-assistant` retiré du meta : sa condition de sortie explicite était remplie AVANT le retrait (rollback natif prouvé T8, chronologie git vérifiée). 10. Contre-test de l'invariant Lua : il a RÉFUTÉ la spec (Hyprland 0.56 charge le Lua même sans `-c`) — spec corrigée, invariant conservé et rejustifié (garantit QUEL fichier). 11. Rendu des pastilles au boot frais : restart unique et détecté de `dms.service`, adjugé sain (conditionnel, stampé, non bouclant, prouvé sur 2 boots du paquet publié) — contournement d'un défaut amont consigné (DMS ne recharge pas `barConfigs` ; note upstream dans la spec §7). 12. Immutabilité du dépôt instaurée (jamais deux octets sous un même pkgrel — sérialisation CI + seed), bumps systématiques y compris pour un commentaire (7→8, adjugé). 13. Dette assumée : `user = seylar` en dur dans greetd.toml (soldée au SP4c avec la fin de l'autologin), auto-login = session sans mot de passe (idem), audio VM invérifiable (`-audio none`).
