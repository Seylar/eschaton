# Plan d'implémentation : le Bureau d'Eschaton

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Statut d'exécution (2026-08-28)** : Tasks 1 à 8 terminées ; Task 9
> techniquement terminée, tag volontairement suspendu à la revue Claude. Les
> écarts découverts en VM sont intégrés ci-dessous ; le détail probant reste
> `tools/vm-dev.md` §§12–17 et `docs/HANDOFF-SP2.md`.

**Goal:** La VM de dogfooding boote en session graphique Hyprland + DankMaterialShell thémée Eschaton, avec deux plugins système fonctionnels — mise à jour et rollback du système depuis le shell — le tout livré en paquets `arch=(any)`.

**Architecture:** Zéro compilation : toute la pile vient des dépôts officiels (Arch + ALARM, versions identiques, veille 2026-08-28). Eschaton livre : un meta-paquet `eschaton-desktop`, un paquet de configuration (`eschaton-desktop-config` — Lua Hyprland, session, greetd par drop-in systemd), et deux plugins DMS système sous `/etc/xdg/quickshell/dms-plugins/` (pacman-owned, lecture seule pour DMS). Les inconnues d'exécution (rendu virtio-gpu, mécanisme de thème DMS) se résolvent par spikes en VM avant d'être packagées.

**Tech Stack:** hyprland (config **Lua** exclusivement), dms-shell-hyprland, quickshell, dgop, greetd, QML/plugin.json (API DMS), Snapper CLI, helper Btrfs via `pkexec`, règles Polkit (JS), bats/shellcheck/qmllint/jq, VM UTM aarch64 (console série). `btrfs-assistant` et un rollback snapperd D-Bus ont été écartés après validation réelle.

**Spec:** `docs/superpowers/specs/2026-08-28-bureau-design.md` (+ veille : `docs/veille/2026-08-28-sp2-bureau.md`, autorité factuelle datée)

## Global Constraints

- Exécution dans le worktree `socle` existant (branche unique jusqu'à la fusion du Socle — voir note de séquencement en fin de plan).
- Tous les paquets SP2 sont `arch=(any)` ; **aucun vendoring, aucun `-git`, aucune recompilation** de la pile bureau (interdits de veille §7.2).
- Config Hyprland en **Lua uniquement** ; l'entrée de session lance **`start-hyprland -- -c ~/.config/hypr/hyprland.lua`** (invariant : sans `-c`, le Lua est ignoré silencieusement).
- Propriété de `~/.config/hypr/` : **DMS possède l'arbre entier**. Les défauts Eschaton vivent dans `/usr/share/eschaton/hypr/` et s'accrochent par une ligne idempotente dans `dms/binds-user.lua`, seul point que `dms setup` préserve.
- `requires_dms` **obligatoire** dans chaque `plugin.json` ; les plugins se jugent contre `extra/dms-shell` (1.5.3), jamais contre `master`.
- Plugins système : `/etc/xdg/quickshell/dms-plugins/<id>/` — jamais le chemin utilisateur, jamais `plugins.lock.json`.
- Motif LICENSE du Socle (symlink `LICENSE -> ../../LICENSE` + install), `sha256sums=(SKIP…)` locaux, pkgrel bump à tout changement de paquet déjà publié.
- Landlock : `--disable-sandbox` sur tout pacman en conteneur ; builds meta en `tools/build-pkg <pkg> -d`.
- VM : pilotage console série (tools/vm-dev.md §5), mot de passe `seylar`/`eschaton`, jamais `ping`, correctifs toujours dans le repo (+ CI verte avant re-test si paquet).
- La validation finale dans la VM se fait sur les paquets **publiés** (CI → Pages → `pacman -Syu`) ; les archives locales ne servent qu'aux boucles de build préalables.

```bash
sleep 15

pgrep -af 'quickshell|dms'                    # les process vivent-ils ?
```

Critères : Hyprland stable ≥ 5 min, process DMS vivants, IPC répond. Rendu visuel : capturer la fenêtre UTM depuis le Mac (AppleScript/`screencapture` de la fenêtre — méthode à établir et documenter ; en dernier recours, constat indirect par hyprctl + absence de crash dans `journalctl --user`).

- [x] **Step 5 : Documenter la décision + l'inventaire dans `tools/vm-dev.md` et committer**

Y consigner aussi : ce que `dms setup` a créé (arbre exact), la liste `pacman -Q` des versions, la méthode de capture d'écran retenue. Nettoyer la VM du spike n'est PAS nécessaire (la Task 7 réinstallera par paquets par-dessus).
